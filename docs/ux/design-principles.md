# Design principles — ApexTweaker

**Data:** 2026-07-25  
**Status:** proposta Fase 1/4

1. **Integridade visual = integridade do SO** — UI nunca esconde risco.  
2. **Uma ação principal** por viewport de fluxo.  
3. **Hierarquia** — título → frase → CTA → detalhes.  
4. **Respiro** — densificar só em listas de settings, não no hero de decisão.  
5. **Progressive disclosure** — log técnico atrás de “Detalhes”.  
6. **Feedback ≤500ms** — senão skeleton/progress.  
7. **Motion funcional** — transição de página curta; sem delay de tarefa.  
8. **Vocabulário humano** — “Reinício necessário”, não códigos crus na linha principal.  
9. **Estados completos** — empty, partial, error, success, restart.  
10. **Aparência por último** — nunca priorizar skin sobre recuperação.
